Model equations used
T_f,i(t_j) = T_i(t_j) − [T_i(t_j) − T_f,i(t_j−1)] · exp[−(Δt_j/τ_i)^β0] ⟨T_f⟩ = Σ_i Y_i T_f,i (weights = equilibrium weights Y_i) T_i = T (2 − T_v,i/⟨T_v⟩) (local temperature) τ_i = τ0 exp[ D T_v,i / (T (1 − T_v,i/⟨T_f⟩)) ] X_i ∝ Y_i (T/D) (1 − T_v/⟨T_f⟩)² τ_eff = exp[Σ X_i ln τ_i] C_p,norm = d⟨T_f⟩/dT D = ln²(100/τ0)/(m ln10 − ln(100/τ0)) T_v = T_g [1 − ln(100/τ0)/(m ln10)]
TNM τ = A exp[ xΔh/RT + (1−x)Δh/RT_f ], Δh/R = m ln10 T_g, ln A = ln100 − Δh/RT_g exact: T_f(t_n) = T_0 + Σ_j ΔT_j {1 − exp[−(Σ_{k=j..n} Δt_k/τ_k)^β]} Prony: T_f,i(t_j) = T − (T − T_f,i) exp(−k_i Δt/τ), T_f = Σ w_i T_f,i
RelaxPy (MAP) log η = y log η_eq(T_f) + (1−y) log η_ne(T,T_f), y = [min(T,T_f)/max(T,T_f)]^p log η_eq = log η∞ + (12 − log η∞)(T_g/T_f) exp[(m/(12−log η∞) − 1)(T_g/T_f − 1)] log η_ne = A + B/T − C exp[−(T_g/T_f)(m/(12−log η∞) − 1)] τ_K = η/K_s; T_f,i(t_j) = T − (T − T_f,i) exp(−k_i Δt/τ_K), T_f = Σ w_i T_f,i
